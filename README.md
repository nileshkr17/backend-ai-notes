# backend-ai-interview-notes

Complete interview prep for **Backend Java + AI/ML roles** — Java internals, Spring Boot, System Design, Security, DSA, and Generative AI engineering.

---

## Files

| File | What's Inside |
|---|---|
| `Java_SpringBoot_MasterRef.md` ⭐ | **The main reference.** 60% explanation + 40% code. All Java + Spring Boot topics: SOLID, OOP, JVM, GC, Collections, Streams, Concurrency, Virtual Threads, all 23 GoF patterns, Spring IoC/AOP/Transactions, JPA, Security, Resilience4j. Nothing you'd hear for the first time in an interview. |
| `Java_SpringBoot_Interview_Prep.md` | Breadth-focused Q&A format — quick revision before an interview. |
| `Java_AppSec_Complete.md` | Java application security from base to architect level: SQL/Command/XXE injection fixes, JWT attacks, OWASP Top 10, BCrypt/Argon2, AES-GCM, deserialization RCE, SSRF defenses, 40-point code review checklist. |
| `HLD_LLD_MasterTemplate.md` ⭐ | **Single template for all system design questions.** Part A: HLD (requirements → estimation → API → architecture → deep dives → NFRs). Part B: LLD (entity extraction, interfaces-first, full Parking Lot with Strategy + State). Part C: Cheat sheet (scaling levels, CAP, availability numbers). |
| `SystemDesign_Sprint_Plan.md` | 13-day system design sprint — all 28 systems from Alex Xu Vol 1+2 mapped day-by-day, with resources and company-specific mock rounds. |
| `DSA_5PerDay_Planner.md` | 38-day, 190-problem DSA planner targeting top product companies. Organized by topic with LeetCode links + company tags. |
| `ai_deep_knowledge.html` ⭐ | AI/LLM engineering deep dive: RAG architecture, vector databases, embeddings, Agentic AI, MCP (Model Context Protocol), prompt injection, hallucination mitigation, anomaly detection, Feature Stores, data drift. |
| `[imp pipeline]java_ai_dev_prep.html` ⭐ | **10 AI topics with mental models + interview answers.** RAG vs Fine-Tuning, AI Agents, ReAct, LangChain vs LangGraph, Prompt Engineering, Function Calling, Vector Embeddings, Spring AI, Incident Triage Agent design, Multi-Agent Orchestration. |
